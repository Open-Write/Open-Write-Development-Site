Standalone application

Open-Write Studio Beta

The full Open-Write pipeline as a standalone Windows 11 application. No VS Code or Kilo Code required. Bundles the Python backend — no installation needed. Supports 22 LLM providers plus local inference via LM Studio and Ollama.

Installer (.exe) 27 MB Installer (.msi) 29 MB

Not yet code-signed. Windows SmartScreen may warn — click More info, then Run anyway. Bugs: GitHub issues.

Version 1.0.5 · Windows 11 · x64 · Free

Open-source pipeline

Open-Write

The full pipeline as Python templates and a CLI toolchain for Visual Studio Code or Kilo Code. Fully customizable — modify any station, swap models, extend the workflow. Three templates: film screenplay, novel, and episodic television.

View on GitHub

Requires Python 3.11+, a code editor, and an LLM API key. See the repository README for setup instructions.

Apache 2.0 · Free
